# Storyboard Generator 交接协议

短剧管家与任意分镜 Skill 通过 `storyboard-package.md` 协作。若使用 `seedance-storyboard-generator`，请确认其已具备以下规则；没有时可将本段作为调用提示附在交接包之后。

短剧管家的启动检查从 `liangdabiao/Seedance2-Storyboard-Generator` 获取其 `.claude/skills/seedance-storyboard-generator` 子目录；只在同级 Skill 缺失时下载，绝不覆盖已有版本。下载必须使用安装脚本内固定的上游提交与 SHA-256 校验，安装账本记录实际版本。

```text
项目交接包优先规则：
当提供 storyboard-package.md 时，本交接包与它引用的 project.yaml、角色圣经、素材索引、冲突清单为最高优先级。
必须覆盖分镜 Skill 的默认受众、画幅、时长、镜头数、节奏和内容尺度；仅当项目字段为空时才可使用默认值。
素材索引中的名称、别名、图片路径和已锁定视觉设定必须保留。先输出梗概、人物小传和大纲，收到确认后再输出剧本和分镜。

若交接包包含“上集承接（锁定）”，其中的已确认事件、角色状态、最后一帧和承接要求属于既定事实：不得自行改写、遗忘或用新设定抵消；若剧情确需变更，必须先让用户确认并回写连续性记录。
```

## 剧本与分镜输出约定

`seedance-storyboard-generator` 负责输出本集的 `formal-script.md` 和 `storyboard.md`。`storyboard.md` 是后续关键帧和图生视频的唯一内容源，默认用导演版逐镜说明，不得以 Markdown 表格替代。先列整体时长、画面规格、固定场景、本集主题和必要视觉设定，再逐镜写完整生产信息。

分镜按剧情节奏、动作、对白和情绪变化智能拆解，默认只使用 5 秒或 10 秒；最后无法凑整时使用不足 5 秒的余数。5 秒 / 余数镜头写“关键帧画面”；10 秒镜头写“首帧 A 画面、尾帧 B 画面”。每镜应包含：镜号、时长、景别、镜头运动、画面关键状态 / 动作过程、台词与口型时间段、非说话嘴型控制、声音策略、音效、入点、出点 / 转场、素材参考、分镜出图提示词。

用户确认剧本与分镜后，短剧管家才可制定关键帧数量。5 秒 / 余数默认 1 张，10 秒默认 2 张。第三张过程帧只可作为有明确原因的 10 秒例外，在关键帧方案中逐镜征得用户明确确认；普通确认未包含该镜时，自动按两帧执行。随后生成的 `keyframe-execution.md` 必须逐镜保留以上字段，新增的仅是首 / 过程 / 尾帧文件、每帧出图提示词和由上述字段合成的视频生成提示词；它不能重新改写剧情，也不能退化成一句动作提示。

这不是对某一版本或某一平台 API 的依赖。它是一条文件级约定：任何遵守该优先级和确认节点的分镜 Skill 都可以接入。
