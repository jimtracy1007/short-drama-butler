# 从分镜到关键帧执行单

`storyboard.md` 是单集画面内容的唯一来源；`keyframe-execution.md` 是它的生产镜像，不可重写故事。

## 字段映射

| 分镜字段 | 执行单字段 | 用途 |
| --- | --- | --- |
| 镜号、时长、景别、运镜 | 原样保留 | 控制视频镜头时长与镜头语言。 |
| 画面内容 | 起点、动作过程、终点 | 决定首、过程、尾帧以及图生视频动作。 |
| 台词、声音策略、音效 | 原样保留 | 明确视频内口型或后期配音，以及声音制作。 |
| 上一镜出点 / 下一镜入点 | 入点、出点 / 转场 | 让剪辑和镜头衔接可执行。 |
| 素材参考、分镜出图提示词 | 原样保留 | 保证视觉素材和静帧出图不漂移。 |
| 无 | `KF<镜号>-start/middle/end.png` 与各帧提示词 | 关键帧执行单唯一新增字段。 |

## 每镜输入契约

生成执行单前，为每个已确认镜头补齐：景别、运镜、场景、按名称的素材参考、起点、动作过程、终点、台词、声音策略、音效、入点、出点 / 转场、原分镜出图提示词，以及与已确认关键帧策略完全对应的 `start` / `middle` / `end` 帧图提示词。

视频提示词由这些字段合成，不得省略时长、画幅、镜头语言、动作三阶段、声音策略、衔接和视觉约束。
