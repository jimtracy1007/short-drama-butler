# EP001《分享的泡泡》分镜交接包

## 固定制作参数

- 受众：3—8 岁
- 画幅：16:9 横屏
- 目标时长：120 秒
- 镜头数量由剧情节奏决定，并综合动作、对白和情绪变化；避免无意义碎镜头。
- 成片路径：每镜关键帧图片 → 豆包图生视频 → 剪辑成集。
- 风格：温暖、明亮、轻松、儿童友好；不得出现恐怖、攻击性、字幕、Logo 或水印。

## 剧情需求

主题：学会分享。咕噜在家里舍不得把心爱的玩具让给朋友；怪怪魔法把玩具变成只会自己转圈的泡泡玩具。请先创作温暖、有小反转、无恐怖或攻击性内容的故事梗概、人物小传和本集大纲，待确认后再写正式剧本与分镜。
