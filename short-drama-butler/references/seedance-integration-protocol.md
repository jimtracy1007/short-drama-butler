# Storyboard Generator 交接协议

短剧管家与任意分镜 Skill 通过 `storyboard-package.md` 协作。若使用 `seedance-storyboard-generator`，请确认其已具备以下规则；没有时可将本段作为调用提示附在交接包之后。

短剧管家的启动检查从 `liangdabiao/Seedance2-Storyboard-Generator` 获取其 `.claude/skills/seedance-storyboard-generator` 子目录；只在同级 Skill 缺失时下载，绝不覆盖已有上游文件。下载必须使用安装脚本内固定的上游提交与 SHA-256 校验。安装、检测，或已装用户拉取管家更新后运行 `butler.py status` / `inspect`，都会把管家自己的 `references/director-board-contract.md` 同步到该 Skill，不必重装第三方目录。远程协作者拿到的是这份合同，不是别人机器上改过的第三方文件。

```text
项目交接包优先规则：
当提供 storyboard-package.md，或项目根目录已有 project.yaml / asset-index.json 时，这些文件与角色圣经、冲突清单为最高优先级。
即使本轮对话没有附交接包，只要项目记忆存在，就必须先读取；不得等用户提醒，也不得仅凭故事文字重新发明已登记外观。
必须覆盖分镜 Skill 的默认受众、画幅、时长、镜头数、节奏和内容尺度；仅当项目字段为空时才可使用默认值。
素材索引中的名称、别名、图片路径和已锁定视觉设定必须保留。先输出梗概、人物小传、本集大纲和“视觉资产分级”，收到确认后再输出剧本和分镜。视觉资产分级逐行写为 `名称 | characters|scenes|props | before_storyboard|before_keyframes|incidental | 理由`：`before_storyboard` 必须先确认图片，`before_keyframes` 等剧本分镜确认后再处理，`incidental` 不创建独立素材。
生成角色、场景、道具或关键帧图片前，必须运行 short-drama-butler/scripts/butler.py inspect 与 dispatch-asset / dispatch-keyframe，并把返回的参考图读进当前对话；禁止纯文生图。

若交接包包含“上集承接（锁定）”，其中的已确认事件、角色状态、最后一帧和承接要求属于既定事实：不得自行改写、遗忘或用新设定抵消；若剧情确需变更，必须先让用户确认并回写连续性记录。
```

## 剧本与分镜输出约定

`seedance-storyboard-generator` 负责输出本集的 `formal-script.md` 和 `storyboard.md`。`storyboard.md` 是后续关键帧和图生视频的唯一内容源，默认用导演版逐镜说明，不得以 Markdown 表格替代。文件开头必须按以下形式逐行写出全局设定；标签和内容必须在同一行，不能拆成“标题一行、内容一行”：

```text
《剧名》<本集目标时长>秒导演版分镜｜<主要场景或版本>
整体时长：<本集目标时长>
画面规格：<画幅、风格与画面限制>
固定场景：<固定场景与空间关系>
本集主题：<主题>
<必要角色、怪物或道具视觉设定>
```

随后才逐镜写完整生产信息。

分镜按剧情节奏、动作、对白和情绪变化智能拆解，默认只使用 5 秒或 10 秒；最后无法凑整时使用不足 5 秒的余数。每个镜头都必须使用以下**独立标题**，不得合并成一句、单元格或表格列：

```text
镜头 N｜5秒｜短标题
关键帧画面
<同一张首帧能表达的完整构图：谁在哪、朝哪看、手/嘴/道具此刻状态。>
动作过程
00:00—00:xx
<短句时间轴。点名角色。手、嘴、道具、镜头在这几秒做什么；台词写在对应节拍内。>
运镜
<景别、机位、镜头运动和落点。>
台词与口型时间段
<精确秒数和说话角色；无台词写“无台词”。>
非说话嘴型控制
<说完立即闭嘴；画外音角色画面内闭嘴；未说话角色闭嘴。>
角色声线
<每个开口角色：年龄/质感/音区 + 这一句怎么说；画外音须标明。无台词写“本镜无台词”。>
声音策略
<视频内口型或后期配音方式。默认无背景音乐。>
音效
<具体拟音，不要写“环境音若干”。>
入点
<承接上一镜。>
出点 / 转场
<交给下一镜的画面或声音。>
素材参考
<按已确认主资产名称列出角色/场景/道具，不要写“只看上一张关键帧”。>
分镜出图提示词
<锁已确认资产身份，只写本帧姿势/机位/光。>

镜头 N｜10秒｜短标题
首帧 A 画面
<开始构图与状态：谁在哪、朝哪看、手/嘴/道具此刻状态。>
尾帧 B 画面
<动作完成后的静帧构图与状态。>
动作过程
00:00—00:xx
<短句时间轴。点名角色。把台词和镜头运动写进对应秒数。>
运镜
<从哪里开始，怎样跟随 / 推拉，最后落在哪里。>
台词与口型时间段
<所有台词均标明落在本镜 0.0–10.0 秒内的口型区间。>
非说话嘴型控制
<说完立即闭嘴；画外音角色画面内闭嘴。>
角色声线
<每个开口角色：年龄/质感/音区 + 这一句怎么说；画外音须标明。>
声音策略
<视频内口型或后期配音方式。默认无背景音乐。>
音效
<具体拟音。>
入点
<承接上一镜。>
出点 / 转场
<交给下一镜的画面或声音。>
素材参考
<按已确认主资产名称列出。>
分镜出图提示词
<锁已确认资产身份，只写本帧姿势/机位/光。>
```

分镜生成完成后、展示给用户确认前，必须运行短剧管家目录下的 `scripts/validate_director_storyboard.py --storyboard <本集 storyboard.md> --target-seconds <本集目标时长>`。校验失败时修正整份分镜并重新校验；不得把不合格的表格或 6 / 7 秒镜头交给用户确认。

用户确认剧本与分镜后，短剧管家才可制定关键帧数量。5 秒 / 余数默认 1 张，10 秒默认 2 张。第三张过程帧只可作为有明确原因的 10 秒例外，在关键帧方案中逐镜征得用户明确确认；普通确认未包含该镜时，自动按两帧执行。随后生成的 `keyframe-execution.md` 必须逐镜保留以上字段，新增的仅是首 / 过程 / 尾帧文件、每帧出图提示词和由上述字段合成的视频生成提示词；它不能重新改写剧情，也不能退化成一句动作提示。

这不是对某一版本或某一平台 API 的依赖。它是一条文件级约定：任何遵守该优先级和确认节点的分镜 Skill 都可以接入。
