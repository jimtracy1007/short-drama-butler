《奇妙岛怪事 / 奇妙岛怪事簿》项目资料库
1. 项目定位
《奇妙岛怪事 / 奇妙岛怪事簿》是面向 3-8 岁儿童的成长习惯类动画项目。
整体气质：温暖、明亮、轻快、可爱、有电影感，不恐怖、不阴森、不低幼。
默认视觉方向：软萌 3D、拟人、高品质家庭动画电影感、皮克斯感但不要太低幼。画面干净、温暖、明亮，角色圆润可爱，表情丰富，动作清楚。
默认做图与视频要求：
默认 16：9横版，除非用户明确要求 9：16 或其他比例。
不要文字、字幕、logo、水印或对话气泡。
必须严格贴合分镜剧情动作和情绪变化。
不要只做“好看海报”，要表现具体剧情。
注意角色、场景、道具连续性，不能跳戏。
2. 核心世界观
故事发生在“奇妙成长岛 / 泡泡湾”。
每个成长小问题如果一直没有被发现或处理，就会悄悄触发“怪怪魔法”。
怪怪魔法不会惩罚谁，而是把小问题变成一场夸张、好笑、看得见的离奇怪事。
怪事簿能感应到怪怪魔法，所以会赶来投出“怪事小剧场”，让大家看清怪事从哪里来、该往哪个方向处理。
泡泡队长再吹出与主题相关的“功能泡泡”，帮助咕噜进入行动。
最后由咕噜亲手完成好习惯动作，让怪事自然消失。
3. 固定叙事公式
每集默认采用以下故事链路：
成长小问题钩子设定 → 怪怪魔法 → 怪事簿小剧场 → 泡泡队长功能泡泡 → 咕噜亲手解决 → 怪事消失 → 独立温暖收束
创作时注意：
每集尽量独立收束，不强行关联下一集。
怪事要夸张、好笑、可视化，但不能吓人。
怪事簿负责“看清原因”。
泡泡队长负责“温柔辅助”。
咕噜必须亲手完成关键好习惯动作。
结尾要让孩子理解：好习惯不是惩罚，而是让身体、房间和朋友关系更舒服。
4. 主要角色设定
4.1 咕噜
男孩小怪兽。
固定外观：
青蓝绿色身体。
奶白肚皮。
小紫角。
头顶水滴卷毛。
大眼睛。
胸前螺旋吊坠。
四根手指。
指甲 / 脚趾甲为和犄角一致的紫色尖尖造型。
禁止：咕噜背后没有翅膀，不能出现翅膀、翅膀状结构、背鳍、翼膜、飞行翅或类似身体结构。
行为连续性：
从外面回来会穿卡通鞋和袜子。
进屋脱鞋脱袜后，后续不能再穿鞋袜，除非分镜明确换上新袜子。
性格：
好奇、活泼、可爱。
会犯成长小错误，但不是坏孩子。
被提醒后愿意学习，并最终亲手改正。
4.2 泡泡队长
半透明蓝色泡泡精灵。
固定外观：
身体像水晶泡泡，有彩虹高光。
戴白色船长帽。
蓝色腰带和小工具包。
表情温柔可靠。
通常漂浮在空中。
动作规则：
吹泡泡时，泡泡必须从嘴里吹出。
不拿工具吹泡泡。
禁止：泡泡队长没有尾巴，不能出现尾巴、尾鳍、尾巴状拖尾或类似身体结构。
禁止：泡泡队长张嘴时，嘴巴里没有牙齿，不能出现露牙、嘴里有牙齿或牙齿形状结构。
功能泡泡必须与本集主题相关，例如牙齿探险泡泡、温水泡泡、放大泡泡、香香追踪泡泡、小手安全泡泡、头发泡泡云、收纳泡泡、安静泡泡、阳光唤醒泡泡、纸巾泡泡、保护泡泡、成长大泡泡。
4.3 怪事簿
深蓝色魔法书。
固定外观：
深蓝封面。
金色包角与金色纹饰。
正面有蓝宝石。
拟人眼睛和小手脚。
眼睛位置在封面上方 / 宝石那一侧上方。
表情随剧情变化。
可合上站立，也可打开投影。
功能规则：
能感应怪怪魔法。
从书本 / 宝石处投出蓝色或绿色发光全息光柱。
投影内容是“怪事小剧场”。
投影要有清晰光线、圆环、泡泡、图标或小剧场层次。
内容要卡通可爱，不恐怖。
4.4 泥巴怪
圆润棕色泥巴拟人角色。
固定外观：
棕色圆润身体。
憨厚可爱。
身体可带泥层、叶片和小石子。
洗干净后仍是棕色泥巴角色，表面干净湿润。
可保留少量叶片和小石子装饰，但不要脏乱。
5. 固定场景与道具
5.1 小怪兽家 / 泡泡屋内景
整体风格：温馨梦幻儿童房，不阴森。
固定元素：
圆形泡泡屋 / 木屋内景。
暖色木质结构。
圆拱门、圆窗。
木梁天花板。
深蓝 / 蓝灰墙面点缀木质星星。
玻璃罩暖黄吊灯 / 小夜灯。
木质书架和小柜子。
童话书、小瓶子、小玩具、小船、球、玩偶、泡泡球。
紫色软垫 / 地毯 / 靠垫，带月亮星星图案。
5.1.1 小怪兽房间固定布置（两张参考图更新）
本节根据本次做图窗口中的“小怪兽房间-对向视角”和“小怪兽房间-平视”两张图，作为后续儿童房场景的固定布置参考。
整体空间：圆拱木屋 / 泡泡屋儿童房，房型是圆的，墙面和天花形成连续弧面；深蓝 / 蓝灰色星星墙面，配胡桃木偏深木色梁架、地板、圆拱门、床、书柜、鞋柜和桌椅。整体白天自然柔光，温暖明亮，带海边童话感，不要改成普通方形卧室、现代公寓或纯浴室。
窗户与光线：房间核心是大圆形观景窗，窗外是明亮蓝天、白云、蓝色海湾、绿岛和远处山石。阳光从圆窗自然照进房间，在木地板和地毯边缘形成柔和光影，不能过曝刺眼，也不能灰暗雾蒙蒙。
窗边软榻：大圆窗下方固定有带抽屉的长窗边软榻，铺蓝色星星软垫和浅蓝星星抱枕，可作为角色坐下休息、看风景、玩玩具的固定区域。
床区：木床位于房间一侧，胡桃木色床架，蓝色星星被子，白色枕头。床上固定放一个黄色星星抱枕和一个紫色月亮抱枕，不要放四个星星抱枕。
地毯与玩具：房间中央是浅蓝 / 蓝灰色短毛茸茸圆形地毯，中心有黄色大星星，外圈有金色星星装饰。地毯上可摆少量积木、蓝绿色球、玩具车等，但不要让地毯显得斑驳、脏乱或花纹过碎。
桌椅与生活物件：前景或侧面可出现圆木桌和蓝绿色星星圆凳。桌上可放水果盘、绘本、画笔、小盘子等儿童生活物件，保持干净、温馨、童话感，不要堆得杂乱。
书柜与装饰：房间内有木质书柜 / 书架、墙面小搁板、床头柜、小柜子、地球仪、书本、小瓶子、小船模型、植物盆栽和星星墙饰。木纹可见但不要过重，颜色统一为偏胡桃木的暖棕色。
吊灯规则：屋顶有多个透明玻璃球吊灯，内有星星装饰，金色顶盖和链条。白天默认关灯不发光，只作为装饰存在；不要改成普通吊灯、强发光灯泡或现代灯具。
门与小圆窗：房间有圆拱木门和多个圆形窗，木门带圆形船舱窗和金色把手，圆形小窗能看到室外海湾或绿岛景色。
鞋柜规则：圆拱暖棕 / 胡桃木色鞋柜靠近门或床边，带星星装饰和多层鞋格，里面整齐摆放多双彩色小鞋。鞋柜位置和造型要与两张参考图保持统一。
水盆区规则：房间一侧保留泡泡湾风格青绿色 / 湖绿色圆润陶瓷水盆，厚边，贝壳、珍珠、金色线条和泡泡装饰；水龙头是弯曲圆润童话造型，青绿色主体、金色底座，不能变成普通水龙头或普通洗手池。
空间连续性：后续做图如果需要“房间对面视角 / 平视 / 四分视角”，必须保持同一个房间的连续性：圆屋弧形墙和木梁、深蓝星墙、胡桃木家具、大圆海景窗、床、鞋柜、水盆、圆桌、短毛星星地毯、少量玩具的位置风格统一，不能每张图换一套房间。
做图禁忌：不要出现文字、字幕、logo、水印或对话气泡；不要让吊灯白天发光；不要让木材过浅或木纹过重；不要把地毯做成斑驳旧毯；不要把墙面星星做得杂乱不均；不要加入大量未设定家具导致跳戏。

固定造型：
泡泡湾风格青绿色 / 湖绿色圆润陶瓷水盆。
厚边。
珍珠、贝壳、金色装饰和泡泡元素。

5.4 第 5 集指甲刀
固定造型：
蓝色手柄。

小型儿童安全指甲刀。
指甲表现规则：
指甲必须自然长在四根手指指尖。
方向正确。

5.5 臭袜子剧情规则
袜子要卡通可爱、轻松搞笑，不恐怖。
脏袜可以有：
灰尘。
汗印。
淡黑烟。
少量黑灰臭泡泡。
避免：
恐怖化。
斑点过多。
过度脏乱恶心。
5.6 第 7 集玩具森林与小熊队长
第 7 集新增固定元素，后续做图、视频和一致性检查都应保持。
小熊队长：全片只有一个毛绒小熊，它就是“小熊队长”。不要出现多个毛绒玩偶、其他小熊或套圈。
小熊队长造型：温暖可爱的毛绒玩偶小熊，柔软、干净、儿童友好；体型要与桌面、玩偶架和小火车车厢比例一致。
小熊队长剧情位置：可坐在小火车小车厢里，被积木桥、轨道迷宫或玩具森林遮挡；后段由咕噜小心抱起，最后安稳坐回玩偶架正中央。
小熊队长禁止表现：不能做成真实动物、机械熊、恐怖玩偶、破旧脏乱玩偶，也不要让表情过度拟人化或抢主角戏。
玩具森林固定元素：彩色积木树、小火车和玩具车轨道迷宫、拼图灌木、半开的图画书小山坡、小鼓、小火箭、积木桥。
收纳道具固定元素：积木盒、车库篮、拼图袋、图画书架 / 书架、玩具柜、收纳区。
儿童房细节：16:9 横版，白天自然柔光，木质圆屋结构、蓝灰星星墙面、圆窗、紫色软垫、玩具柜、收纳区统一。
吊灯细节：屋内吊灯统一为封闭玻璃圆形吊灯，金色顶部和底部装饰；白天关灯，不发光。
动作规则：怪事簿只负责还原真相和投影；泡泡队长吹出收纳泡泡和发光路线辅助；咕噜与泥巴怪亲手分类收纳，玩具森林才缩小，小熊队长才被找回。
画面限制：不要加入未设定的大量新玩具，不要让背景玩具、毛绒玩偶数量过多导致画面跳戏。
6. 第一季 12 集资料
第 1 集《半夜，牙齿城堡传来敲门声》
主题：睡前刷牙。
成长小问题：睡前偷吃软糖，却忘了刷牙。
怪事：半夜牙齿里传来“咚咚咚”的敲门声，糖果虫在牙齿城堡里搬家。
怪事簿小剧场：珍珠白牙齿城堡里，糖渣堆成小山，糖果虫背小包袱、推糖渣小车往牙缝里钻。
泡泡队长功能泡泡：牙齿探险泡泡。
咕噜解决动作：认真刷牙，刷外面、里面和咬合面。
收束：牙齿城堡重新亮起来，第二天咕噜主动刷牙。
第 2 集《泥巴怪越晒越硬》
主题：玩泥后清洁。
成长小问题：玩泥后不想清洗，舍不得“泥巴盔甲”。
怪事：太阳一晒，泥巴盔甲变成硬泥壳，泥巴怪被卡成滑稽石雕。
怪事簿小剧场：硬泥壳遇到温水泡泡会慢慢变软。
泡泡队长功能泡泡：温水泡泡。
咕噜解决动作：观察泥壳变化，配合温水泡泡帮泥巴怪洗净。
收束：泥巴怪变得干净、轻盈、Q 弹。
第 3 集《手心里的细菌迷宫》
主题：饭前洗手。
成长小问题：小手没洗就想吃东西。
怪事：咕噜手心变成绿色迷宫，小细菌推着饼干碎屑在掌纹、手背和指缝里乱跑。
怪事簿小剧场：小细菌在手心里开派对，想爬向饼干。
泡泡队长功能泡泡：放大泡泡。
咕噜解决动作：洗手，搓手心、手背和指缝，清水冲干净。
收束：细菌迷宫消失，咕噜用干净小手安心吃饼干。
第 4 集《臭袜子飞走了》
主题：袜子及时换洗、放回该去的地方。
成长小问题：换下来的袜子不换洗、不放好，随手丢在鞋柜旁。
怪事：鞋柜冒出黑烟，两只臭袜子长出黑翅膀，在屋里乱飞。
怪事簿小剧场：没换洗的袜子堆满鞋柜，臭味变成黑灰色小臭泡泡，鞋柜变成“臭泡泡山”。
泡泡队长功能泡泡：香香追踪泡泡。
咕噜解决动作：顺着臭味轨迹找回飞袜子，把袜子放进洗衣盆，并整理鞋柜。
收束：臭泡泡和黑烟消失，泡泡屋恢复清爽整洁，咕噜换上干净袜子。
第 5 集《长指甲钩住玩具车》
主题：安全剪指甲。
成长小问题：指甲太长没有修剪。
怪事：长指甲像小钩子，钩住玩具车、毛巾、积木缝和衣角。
怪事簿小剧场：小爪子的长指甲变成弯钩，把玩具、毛巾、衣服全串在一起。
泡泡队长功能泡泡：小手安全泡泡。
咕噜解决动作：看清指甲白边，只剪白白长出来的部分，剪完洗手。
收束：玩具车顺利冲过终点，咕噜展示短短圆圆的小指甲。
第 6 集《洗头泡泡云来了》
主题：克服洗头害怕、清洁头发。
成长小问题：头发里夹着沙粒和叶片，却害怕水进眼睛不想洗头。
怪事：头顶冒出软绵绵的泡泡云，头发变乱变硬。
怪事簿小剧场：发丝变成小森林，沙粒小怪和叶片在里面搭窝、打结、荡秋千。
泡泡队长功能泡泡：头发泡泡云，先变成护眼小帽，再像小雨一样轻轻洗头。
咕噜解决动作：揉搓头发，冲水，把沙粒和叶片洗掉。
收束：水滴卷毛恢复柔软亮晶晶，咕噜发现洗头不可怕。
第 7 集《玩具森林吞掉小熊》
主题：收拾玩具、分类归位。
成长小问题：玩完玩具不收，玩具不回家。
怪事：玩具堆长成乱糟糟的玩具森林，小熊被藏住。
怪事簿小剧场：积木长成树，小车轨道变成弯路，小球像藤蔓滚来滚去，小熊被玩具枝条挡住。
泡泡队长功能泡泡：收纳泡泡。
咕噜解决动作：把积木、小车、拼图、小球、毛绒玩具分类送回家。
收束：玩具森林消失，小熊回到架子上，房间变整洁。
第 7 集视觉补充：小熊回到架子上时，默认是“小熊队长”安稳坐回玩偶架正中央；画面里不要再出现第二只毛绒小熊或其他毛绒玩偶抢戏。
第 7 集道具补充：玩具森林由积木树、轨道迷宫、拼图灌木、图画书小山坡、小鼓、小火箭和积木桥组成；收纳路线指向积木盒、车库篮、拼图袋和图画书架。
