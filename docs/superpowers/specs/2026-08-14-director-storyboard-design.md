# 导演版分镜与关键帧节奏设计

## 目标

将短剧管家与 `seedance-storyboard-generator` 的默认分镜输出统一为可直接交给图生视频流程的导演版逐镜文档。它不绑定某个视频平台，也不改变既有的“剧本与分镜确认 → 关键帧方案确认 → 出图”的关口。

## 已确认的产品规则

1. 分镜根据剧情、动作、对白和情绪变化智能拆分；默认时长仅使用 5 秒或 10 秒。
2. 如果整集目标时长除以 5 秒有余数，最后一个镜头使用余数秒；不能为了凑整增加无意义镜头。
3. 5 秒镜头默认 1 张关键帧（`start`）。
4. 10 秒镜头默认 2 张关键帧（`start`、`end`）。
5. 过程帧（`middle`）是例外：仅当镜头包含不可由首尾帧表达的中间状态，例如变形、魔法、分阶段动作、复杂走位或关键反转时，方案可提出 3 张；必须写出原因并逐镜等待用户明确确认。普通的关键帧方案确认不视为过程帧确认；未被明确确认的镜头仍保持 2 张。
6. `storyboard.md` 默认不用 Markdown 表格，而使用“导演版逐镜说明”格式；表格只可作为机器可读的辅助产物，不能替代正文。

## 方案比较

| 方案 | 结果 | 取舍 |
| --- | --- | --- |
| A：在两个 Skill 与关键帧脚本中统一合同（采用） | 无论单独或联动使用，都遵守同一时长、格式和确认规则 | 需要同步更新文档、交接包和测试。 |
| B：只在短剧管家加覆盖提示 | 联动时有效，单独使用 Storyboard Generator 会退回旧表格 | 不满足“默认改掉”。 |
| C：只靠用户每次口头提示 | 不改代码和 Skill | 容易遗忘，无法可靠生产。 |

## 导演版输出合同

`storyboard.md` 的顺序固定为：

1. 标题：`《剧名》<时长>秒导演版分镜｜<主要场景或版本>`。
2. 整体时长、画面规格、固定场景、本集主题，以及只在本集出现的关键视觉设定。
3. 每个镜头使用 `镜头 N｜<时长>秒｜<短标题>`。
4. 5 秒或余数镜头写“关键帧画面”；10 秒镜头写“首帧 A 画面”“尾帧 B 画面”；已获用户确认的三帧镜头额外写“过程帧 B 画面”和“尾帧 C 画面”。
5. 每镜都必须有：运镜、台词与口型时间段、非说话嘴型控制、声音策略、音效、入点、出点/转场、素材参考、分镜出图提示词。
6. 所有台词时间均落在该镜头时长内；非说话角色明确闭嘴或仅做非口型动作；除非项目配置另有要求，画面不出现文字、字幕、Logo、水印或对话气泡。

## 实现边界

- `seedance-storyboard-generator` 负责按本合同生成正式剧本与导演版分镜。
- 短剧管家在 `storyboard-package.md` 中写入覆盖规则，并在 `keyframe-plan.md` 中将时长映射为默认帧数。
- `project_files.py` 只执行可验证的规则：默认映射、第三帧需要理由与逐镜显式确认（未列入确认镜号即降为两帧）、生成执行单时保留逐镜信息。
- 不新增视频 API、视频生成或自动剪辑；不上传项目图片。

## 验收与测试

1. 5 秒、10 秒和余数镜头生成的关键帧方案分别为 1、2、1 张。
2. 请求 10 秒三帧但没有“特殊原因”时，创建方案必须失败；方案未获用户确认时，执行单必须失败。
3. 通过显式过程帧理由并经用户确认后，执行单才包含 `middle` 文件。
4. 交接包、两个 Skill 规则与 README 都不再将表格、2–5 秒或 15 秒短视频模板作为默认导演版分镜输出。
5. Skill 校验、单元测试和现有脚本回归检查通过。
